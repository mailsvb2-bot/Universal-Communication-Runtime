Моё устройство

Проверка независимой авторизации…

Вход возможен только с ранее зарегистрированным Device и его сохранённым ключом. Новый Device требует отдельного подтверждения или восстановления — идентификатор сам по себе не даёт доступа.

Контакты

Идентификатор собеседника необходимо независимо проверить. Имя и телефон не являются доказательством личности. Адресная книга зашифрована на устройстве.

    Входящие звонки

      В этом браузерном варианте входящие проверяются только при открытом приложении. Фоновые мобильные уведомления ещё требуют отдельного провайдера.

      Текущий вызов

      Нет активного вызова.

      Состояние защиты

      До подтверждения учётной записи и Device камера и микрофон не включаются.
