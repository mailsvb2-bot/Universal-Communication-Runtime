# Phase 17 Chat nonclaims

Phase 17 does not claim Phase 18 Groups or later communication layers.

Not implemented by this phase: group membership/roles/invites/moderation, attachments/file transfer, edit/delete/reaction workflows, thread lifecycle, forwarding workflow, durable presence, calls/WebRTC/SFU, discovery, Relay/NAT traversal, route orchestration/failover, Reference Messenger UI, or Production listener hardening.

These are explicit phase boundaries, not silent TODOs inside the Phase-17 direct-chat runtime.
